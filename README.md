# APEX CIRCUIT 3D

Three.js と Web Audio API で構築された、3D一人称視点（コックピット視点）サーキット・カーレースゲームです。

👉 **公開プレイURL (GitHub Pages)**: [https://qua2psy10-web.github.io/game-carrace/](https://qua2psy10-web.github.io/game-carrace/)

## 特徴
- **3Dコックピット内装（一人称視点）**: ステアリング連動、リアルタイム更新されるデジタルメーター（RPM・シフトインジケーター・ギア・スピード・ラップ表示）
- **バックミラー（ルームミラー）**: 後方カメラのリアルタイム映像を画面上部のルームミラーに描画
- **デモ走行（AI自動運転・観戦）モード**: 操作せずにコックピット視点・TV中継カメラ・チェイスカメラ・シネマティックカメラで走りを観戦可能（自動カメラ切替・観戦マシン切替・途中からの手動運転引き継ぎ対応）
- **サーキット3周レース**: 5台のAIライバル車との順位争い、ラップタイム＆ベストラップ計測、ミニマップ表示
- **Web Audio API サウンドエンジン**: 外部音声ファイル不要のリアルタイム合成エンジン音、タイヤスキッド音、縁石ランブル音

## 遊び方
`index.html` をブラウザで開くか、上記の GitHub Pages URL にアクセスするだけでプレイできます。

### 操作方法
- `W` / `↑` : アクセル
- `S` / `↓` : ブレーキ / バック
- `A` `D` / `←` `→` : ステアリング
- `Space` : ハンドブレーキ（ドリフト）
- `V` : カメラ視点切り替え（コックピット1人称 / TV中継カメラ / チェイス3人称 / シネマティック）
- `P` : デモ走行（AI自動運転）ON / OFF 切り替え
- `C` : デモ観戦中のカメラ自動スイッチ ON / OFF
- `Tab` : デモ観戦中のターゲットマシン切り替え（全6台）
- `M` : サウンド ON / OFF
- `R` : リスタート
