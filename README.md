# APEX CIRCUIT 3D

Three.js と Web Audio API で構築された、3D一人称視点（コックピット視点）サーキット・カーレースゲームです。

## 特徴
- **3Dコックピット内装（一人称視点）**: ステアリング連動、リアルタイム更新されるデジタルメーター（RPM・シフトインジケーター・ギア・スピード・ラップ表示）
- **バックミラー（ルームミラー）**: 後方カメラのリアルタイム映像を画面上部のルームミラーに描画
- **視点切り替え**: `V` キーでコックピット視点（1人称）とチェイスカメラ視点（3人称）を切り替え可能
- **サーキット3周レース**: 5台のAIライバル車との順位争い、ラップタイム＆ベストラップ計測、ミニマップ表示
- **Web Audio API サウンドエンジン**: 外部音声ファイル不要のリアルタイム合成エンジン音、タイヤスキッド音、縁石ランブル音

## 遊び方
`index.html` をブラウザで開くだけでプレイできます。

### 操作方法
- `W` / `↑` : アクセル
- `S` / `↓` : ブレーキ / バック
- `A` `D` / `←` `→` : ステアリング
- `Space` : ハンドブレーキ（ドリフト）
- `V` : 一人称 / 三人称 視点切り替え
- `M` : サウンド ON / OFF
- `R` : リスタート
